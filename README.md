# SpotShare 🏡✨

A full-stack MERN (MongoDB, Express, React, Node.js) web application for hourly space rentals. SpotShare allows users to explore unique locations, book spaces with real-time price calculation, complete secure checkouts, and manage reservations through dedicated user and admin dashboards.

## 🚀 Key Features

* **Edge-to-Edge Responsive Layout:** Custom CSS grid architecture built for optimal viewing across all screen sizes.
* **Secure Authentication:** User login, registration, and role-based access control (Guest / Host / Admin) with anti-autofill input protection.
* **Interactive Search & Filtering:** Filter spaces by location or category (Studio, Event, Meeting, Outdoor, Villa, Soundstage).
* **Dynamic Checkout:** Real-time booking duration pricing with Stripe Credit Card formatting, UPI QR simulation, and Pay on Arrival options.
* **User & Admin Dashboards:** Track active bookings, download receipts, cancel reservations, and monitor platform statistics (admin panel).

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Vite, Axios, Custom CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Version Control:** Git & GitHub
